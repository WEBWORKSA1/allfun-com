# AllFun.com

Free original browser games, daily puzzles, trivia and personality quizzes, party and classroom tools, idea guides and fun facts — plus a free event-planning lead service, a printable Game Night Kit, monthly contests, reader support, creator hiring and sponsorships.

- **Live (GitHub Pages):** https://webworksa1.github.io/allFun-com/
- **Domain:** allfun.com — point DNS at GitHub Pages (A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; `www` CNAME `webworksa1.github.io`), then enter `allfun.com` under *Settings → Pages → Custom domain* and tick *Enforce HTTPS*. AdSense and `ads.txt` require the custom domain.
- **Stack:** static HTML/CSS/vanilla JS generated by `_build/build.py` (Python 3 + `markdown`). The workflow `.github/workflows/deploy.yml` builds the pages, renders the share image and icons, and publishes to GitHub Pages on every push to `main` (free plan). Pages source must be set to **GitHub Actions** (*Settings → Pages → Build and deployment*).
- Generated HTML is not committed — edit the sources below and push; the site rebuilds itself.

## Edit and rebuild
```
pip install markdown
python3 _build/build.py
```

| What | Where |
|---|---|
| Payments (PayPal / Stripe / Ko-fi / Buy Me a Coffee links) and site settings | `assets/js/config.js` |
| Games and tools copy | `_build/catalog.py` |
| Home, lead gen, contests (prizes), support, careers, advertise, legal pages | `_build/static_pages.py` |
| Idea guides / fact collections (Markdown) | `_build/content/guides/`, `_build/content/facts/` |
| Game Night Kit | `_build/content/kit.md` |
| Quiz, would-you-rather, charades, activities | `assets/data/*.json` |
| FiveWord daily answers (guess list is added at build time) | `_build/data/answers5.txt` |
| Game code | `assets/js/games/*.js` |

Forms post to a FormSubmit relay whose address is assembled at runtime from encoded parts in `config.js`; the first submission from a new domain triggers a one-time activation email.

See `PROMPTS.md` for the business case and phase-wise build prompt, and `RESEARCH.md` for the 52-site competitive review.
